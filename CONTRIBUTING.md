# Contributing

Contributions that improve reproducibility, testing, documentation, numerical stability, or explicit falsification criteria are welcome.

Before proposing a change:

1. preserve the distinction between programmed assumptions and emergent observations;
2. document changed parameters and random seeds;
3. add or update a test when behavior changes;
4. do not describe numerical agreement as an ontological proof or first-principles derivation;
5. keep CoMath V8 mathematical material distinct from FUT-facing physics conjectures.

Bug reports should include the script name, Python and dependency versions, operating system, command used, seed, full traceback, and the smallest reproducible parameter set.
